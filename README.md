XinSteam-Fluent：一款简约克制的 Steam 游戏入库助手

XinSteam-Fluent 是一款面向 Steam 玩家的桌面辅助工具，专注于解决游戏入库过程中的搜索不便、资源获取复杂、管理零散等问题。它采用 WinUI 3 原生框架，界面简洁流畅，所有交互都经过精心打磨，力求让每次操作都自然、高效。

智能搜索与推荐
无论你输入游戏名称、AppID 还是 Steam 商店链接，它都能快速定位到对应游戏，并以卡片形式呈现名称、简介和封面图。卡片上支持右键复制 AppID、Steam 链接，或直接跳转商店。首页的“精选游戏推荐”会从数千款游戏中随机抽取，并分页展示，每次打开都有新发现。

灵活的游戏库管理
工具会自动检测你已入库的游戏，并以网格展示。你可以复制任意游戏信息、一键擦除个别条目或清空整个库。切换内核模式（ST / OST）时，程序会先自动关闭 Steam，避免文件冲突，同时保留重启提示，不打扰你的游戏进程。

稳定可靠的下载体验
下载过程透明可控：实时显示进度、剩余时间和当前使用的下载源（例如“国内源”或“镜像站”）。支持暂停、取消，下载完成后弹窗询问是否重启 Steam，不会强制中断你的游戏。即使某个源失效，也会自动切换到备用源，保证入库成功率。

细节与克制

· 首次启动有简洁的三步向导，只需选择内核模式并同意协议，后续不再打扰。
· 所有设置（主题、GPU 渲染、内核模式）都保存在本地，重启不丢失。
· 下载列表的文字实时刷新，无需切换页面即可看到状态变化。
· 窗口标题栏融入系统亚克力效果，按钮背景透明，视觉上干净利落。

最后
XinSteam-Fluent 不捆绑任何商业服务，不收集用户信息。它只是一个帮助玩家更轻松管理 Steam 游戏的小工具，保持简单、克制，将选择权留给你。
